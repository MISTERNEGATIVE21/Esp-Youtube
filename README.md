# Esp-Youtube

Running Youtube in Esp32 using an intermediate Server.

## Description

This project demonstrates how to run YouTube on an ESP32 microcontroller using an intermediate server to handle the heavy lifting. The ESP32 is a low-cost microcontroller with Wi-Fi and Bluetooth capabilities.

## How to Run

1. Clone the repository:
    ```sh
    git clone https://github.com/MISTERNEGATIVE21/Esp-Youtube.git
    ```
2. Follow the instructions in the `setup.md` file to configure your environment.
3. Build and upload the code to your ESP32.
